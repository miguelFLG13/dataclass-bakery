Generators
============

Dataclass Bakery has different generators to generate data depending on the dataclass attributes typing, we are working to develop more generators, but now we have these:

Every container generator (Dict, List, Tuple, Set, Frozenset, Deque, OrderedDict, Counter, Defaultdict) also works with **nested** typings, e.g. ``List[List[int]]`` or ``Dict[str, List[int]]``, and their items can themselves be an Enum, a Literal, a Union/Optional or another dataclass.

``Union[X, Y, Z]`` (and ``Optional[X]``, which is ``Union[X, None]``) picks a real random member among all the non-``None`` options on every call, not just the first one declared.

``dataclasses.dataclass``, ``typing.NamedTuple`` and ``typing.TypedDict`` classes are all supported as attribute typings and generated the same way: each of their fields is randomized following the same rules as a top-level dataclass.

Complex Generator
------------------

`from dataclass_bakery.generators.random_complex_generator import RandomComplexGenerator`

Generator for a random `complex` number, for example:

- Attribute example:

::

    price: complex

- The complex generator generate: `(1.3+5.2j)`


Defaults: 

    - _min_limit_ = 0 (Minimun limit of the real and imaginary part) 
    - _max_limit_ = 100 (Maximun limit of the real and imaginary part)
    - _decimals_ = 2 (Maximum figures of the decimal part)


Counter Generator
------------------

`from dataclass_bakery.generators.random_counter_generator import RandomCounterGenerator`

Generator for a `Counter` (from collections import Counter), for example:

- Attributes example:

::

    first_counter: Counter
    second_counter: Counter[str]

- The Counter generator generate in both cases: `Counter({"key1": 5, "key2": 12})`

Defaults:

    - _max_length_ = 2 (Amount of different items counted)
    - _default_value_type_ = str (Typing of the counted items, if you don't specify with Counter[])
    - _min_limit_ = 0 (Minimun value of the count)
    - _max_limit_ = 100 (Maximun value of the count)

Defaultdict Generator
-----------------------

`from dataclass_bakery.generators.random_defaultdict_generator import RandomDefaultdictGenerator`

Generator for a `defaultdict` (from collections import defaultdict) or a `DefaultDict` (from typing import DefaultDict), for example:

- Attributes example:

::

    first_defaultdict: defaultdict
    second_defaultdict: DefaultDict[str, int]

- The defaultdict generator generate in both cases: `defaultdict(<class 'int'>, {"key1": 1, "key2": 2})`

The ``default_factory`` used is the value type itself (matching the conventional ``defaultdict(int)``, ``defaultdict(list)``... usage), so a missing key returns the type's zero value instead of raising ``KeyError``.

Default values:

    - _max_length_ = 2 (Length of the generated defaultdict)
    - _default_key_type_ = str (Typing of the keys, if you don't specify with DefaultDict[])
    - _default_value_type_ = int (Typing of the values / default_factory, if you don't specify with DefaultDict[])
